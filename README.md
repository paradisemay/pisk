# Pisk

## Запуск
1. Требуется JDK 21+ и Maven Wrapper.
2. Собрать и запустить: `./mvnw spring-boot:run`
3. Swagger UI доступен после старта по адресу [`/swagger-ui.html`](http://localhost:8080/swagger-ui.html).

## Фронтенд
Интерфейс собран на Spring MVC + Thymeleaf, статические ресурсы лежат в `src/main/resources/static`, шаблоны — в `src/main/resources/templates`.

- Обновления фронта автоматически упаковываются при `./mvnw package`/`./mvnw spring-boot:run`, отдельный npm-билд не требуется.
- Для разработки достаточно менять CSS/JS/HTML в статике и перезапускать приложение (или использовать devtools).

## Основные страницы
- `/catalog` — каталог с фильтрами/сортировкой/пагинацией через query-параметры.
- `/tracks/{id}` — карточка трека с плеером и рейтингом.
- `/authors/{id}` — профиль автора.
- `/upload` — загрузка трека с валидацией и сообщениями рядом с полями.
- `/admin` — админ-панель с настройками.

Переключение языка RU/EN осуществляется через параметр `lang` в URL (MessageSource + CookieLocaleResolver).

## Хранилище

- Аудио треков — `storage/tracks/{artistId}`; внутри каждой папки лежат файлы треков конкретного исполнителя.
- Обложки — `storage/covers`.
- Аватары (опционально) — `storage/avatars/{userId}`.

**Правила именования и контент-ограничения**

- Имена файлов — `kebab-case` или цифровые `ID` без пробелов; расширения должны отражать реальный формат (`.mp3`, `.flac`, `.wav` для аудио; `.jpg`/`.jpeg`/`.png` для изображений).
- Максимальный размер: аудио до 30 МБ, обложки/аватары до 2 МБ.
- Запрещены исполняемые файлы и встроенные архивы; изображения должны быть без анимации и без прозрачности для обложек (чтобы избежать артефактов при ресайзе).
- Рекомендуется держать аудио в `320 kbps mp3` или без потерь, изображения — 1:1 для аватаров и 1:1/1.5:1 для обложек (до 2000px по большей стороне).

**Ручное добавление треков разработчиком**

1. Создайте (при необходимости) папку исполнителя `storage/tracks/{artistId}` и поместите аудио-файл с именем, совпадающим с `trackId` или slug трека.
2. Положите обложку в `storage/covers` с таким же базовым именем, что и аудио (например, `trackId.jpg`).
3. Если нужен аватар автора, добавьте файл в `storage/avatars/{userId}` с именем `userId.ext`.
4. Убедитесь, что размеры и форматы соответствуют ограничениями выше; при необходимости прогоните сжатие/нормализацию громкости.
5. Проверьте, что метаданные трека и связки `artistId`/`trackId`/`cover` прописаны в базе данных или seed-скриптах; затем перезапустите приложение, чтобы обновить кэш/индексы.
